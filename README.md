# 油站计量枪检定排期台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

预置五座油站（成都五个区域）及其加油枪，地图标记油站位置。同区域选 2-4 把枪建立检定批次，数据仅保存在浏览器 localStorage（键：`gas-gun-calendar-v1`），可一键恢复预置数据。

## 业务规则

1. 建批须同区域 2-4 把枪；任一枪存在以下情况则**整单拒绝，原批次与标记不变**：
   - 已有未结束批次（枪号被锁定）；
   - 枪状态非营业（停用/维修）；
   - 检定剩余有效期超过 7 天。
2. 批次锁定枪号与建批时油品；逐枪登记完成日，全部完成后按**最晚完成日统一延期 180 天**。
3. 在批期间枪被停用或改油品时**自动撤出**，有效期恢复入批前原值；撤出枪不参与完成延期；全部撤出的批次自动撤销。

## 文件拆分（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 领域类型、预置油站/油枪、日期工具、建批校验、撤出与延期规则（纯函数，不碰存储与 DOM） |
| `src/storage.ts` | 响应式状态、localStorage 读写、动作编排（建批/完成/停用/改油品） |
| `src/ScheduleBoard.vue` | 界面：Leaflet 地图、油枪选择建批、拒绝原因、批次排期卡片 |

`App.vue` 仅挂载界面组件；`main.ts` 为入口。
